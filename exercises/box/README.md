# Exercițiu — Box model

Pornind de la o cutie goală, exersează proprietățile box model-ului.

## Cerințe

1. `.box` are 300px lățime și 300px înălțime, un `background-color`, colțuri rotunjite (`border-radius: 10%`) și o umbră (`box-shadow`).
2. Paragraful din cutie:
   - text centrat, un font sans-serif și o culoare deschisă care contrastează cu fundalul;
   - `padding: 10px` și un `border` de 2px;
   - `margin` diferit pe fiecare latură, scris în forma scurtă: `margin: 100px 30px 50px 80px`.
3. Deschide DevTools → **Computed** și identifică în diagrama box model-ului fiecare valoare setată.

Întrebare: de ce paragraful pare că „împinge” cutia în jos când îi pui `margin-top`? (indiciu: margin collapsing)
